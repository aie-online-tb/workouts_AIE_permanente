# Guion vídeo — Primera API FastAPI / CRUD (~10–12 min)

1. **Contexto (1 min):** demo para pillar FastAPI + Pydantic (aún sin IA).
2. **Arranque (2 min):** venv, `uvicorn`, abrir `/docs`.
3. **GET (2 min):** `/items`, `/items/{id}`, query `on_offer`, forzar 404.
4. **POST (3 min):** crear ítem; 409 duplicado; 422 con `price` inválido.
5. **PUT + DELETE (2 min):** actualizar y borrar; comprobar listado.
6. **Cierre (1 min):** memoria ≠ DB; `/ask` e IA → Bloque 2.
